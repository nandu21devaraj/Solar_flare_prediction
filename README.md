# 🌞 Solar Flare Prediction – Project Presentation

This repository contains the **project presentation (PPT)** for the Solar Flare Prediction system using deep learning.

---

## 📌 About the Project

This project focuses on predicting solar flares using **Convolutional Neural Networks (CNN)** trained on:

* Solar magnetogram images (JSOC)
* Solar activity data (NOAA)

The system achieves **~91% accuracy** and is deployed using a **Streamlit web application** for real-time prediction.
